## Background

apple-music-mcp exposes Apple Music as an MCP server — play / pause, queue,
search, create playlists — so I can drive the Mac's music app from inside a
Claude Code session or any other MCP-aware client. Under the hood it talks to
the macOS Music.app via AppleScript / ScriptingBridge, wrapping those calls in
an MCP-shaped tool surface.
