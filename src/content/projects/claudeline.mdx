## Background

claudeline is a configurable status line for Claude Code — the bar you see at
the bottom of the terminal session. It stitches together the bits of context
that matter mid-conversation: current git branch and dirty state, session cost,
token usage against your plan limit, and a couple of theme options. It's
distributed as an npm package and wires into Claude Code's `statusLine` setting
hook.
