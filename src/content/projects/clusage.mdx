## Background

clusage is a small native macOS menu bar utility that aggregates Claude API
usage across multiple accounts into one glanceable view. It sits in the menu
bar, polls each configured account, and surfaces current spend, rate-limit
headroom, and recent activity. Written in Swift with zero third-party
dependencies, following the same house rules as the rest of SevenTwo Studio's
native work.
