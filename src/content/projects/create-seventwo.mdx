## Background

create-seventwo is the scaffolder I reach for when starting a new SevenTwo
Studio project. It generates a Bun-based monorepo pre-wired with everything I
don't want to set up by hand again: Cloudflare Workers with static assets,
Drizzle + D1, Better Auth, Hono, Biome, and CI workflows. It's the embodiment
of my stack preferences — running it gives you a project that already matches
how I work by default.
