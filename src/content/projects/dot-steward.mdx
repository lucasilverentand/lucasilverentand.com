## Background

dot-steward is a Rust CLI for managing dotfiles declaratively. Instead of
hand-rolled symlink shell scripts, you describe your desired state in a
config file and dot-steward reconciles it: creates the symlinks, tracks what
it owns, and cleans up when entries go away. Designed to be safe on a fresh
machine and idempotent on a repeat run.
