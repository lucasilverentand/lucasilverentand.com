## Background

ha-inhabit is a Home Assistant custom component that adds a visual editor for
defining rooms, zones, and sensor groupings, then exposes those structures
back to HA as first-class entities you can drive automations from. Instead of
wiring room semantics into YAML by hand, you sketch the house once and the
component keeps the state model in sync.
