## Background

This site. Built with Astro, deployed as a single Cloudflare Worker with
static assets (not Pages) so server routes, D1, and any future runtime bits
all live in one place. Content is Markdown/MDX: a blog collection for
writing, a projects collection for portfolio pieces, each rendered through
typed Astro content collections. Styling is Tailwind v4 with a tokenized dark
mode via `data-theme` overrides.
