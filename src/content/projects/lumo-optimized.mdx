## Background

Lumo Optimized is a curated Fabric modpack for Minecraft 1.21.8, tuned for
performance on modest hardware without giving up on visual polish. It pairs
Sodium-family rendering optimizations with a deliberately chosen set of
quality-of-life and visual mods, all managed through packwiz so the manifest
stays reproducible. Built for running the family and friends Minecraft server
paired with lumo-server.
