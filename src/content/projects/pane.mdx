## Background

pane is a Rust TUI for running and supervising multiple Claude Code agents in
parallel — each in its own worktree, each with its own task. It's three
pieces: a background daemon that owns agent lifecycles, a wire protocol for
talking to it, and a terminal UI that lets me tail logs, switch between
sessions, and queue up work without juggling a dozen tmux panes.
