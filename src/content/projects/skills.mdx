## Background

This repo is a curated library of Claude Code skills — 72 of them, grouped
into 16 topical plugins (git, testing, docs, etc.) and 7 intent-based bundles
(like "clean up a repo" or "ship a release"). Skills are small, composable
prompts that Claude Code auto-loads when the right trigger phrase shows up in
a conversation, so the goal is high signal-to-noise: each one is tuned to
activate only when it's actually useful.
