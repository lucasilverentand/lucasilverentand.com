## Background

tarmac is a native macOS app that provisions ephemeral GitHub Actions runners
inside macOS VMs on Apple Silicon using Apple's Virtualization framework. Each
job gets a clean, disposable VM, so builds can't leak state between runs. It's
aimed at replacing the hosted macOS runner bill for SevenTwo Studio's iOS and
macOS CI pipelines.
