## Background

tkn is a Rust shell proxy that wraps noisy CLI commands and trims their output
before it hits an AI coding assistant's context window. Think `find`, `ls -R`,
`npm install`, verbose test runners — commands that routinely dump thousands of
tokens of repetitive noise. tkn collapses that into a digest (paths and counts
instead of full trees, errors instead of full logs) and caches the full output
behind a reference you can expand on demand.
