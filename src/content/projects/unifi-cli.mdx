## Background

unifi-cli is a TypeScript CLI for Ubiquiti's UniFi Network controller that
also doubles as an MCP server — so the same 67 commands can be driven from a
shell or from an AI assistant like Claude Code. Commands are auto-generated
from UniFi's OpenAPI description, which means a single code-gen pass keeps it
in sync as the controller API evolves instead of having to hand-maintain every
endpoint.
